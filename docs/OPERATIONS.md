# Governed customs operations

Run bootstrap, configure `.env`, migrate, provision tenant memberships, then start. The launcher is non-destructive and does not install, drop/create databases, migrate, seed, or kill port owners. Demo seeding is explicitly guarded.

The governed case API retains immutable intake snapshots and hashes, effective-dated tariff/watchlist source versions, classification rationale, screening thresholds and scores, license exceptions, distinct dual approvals, optimistic concurrency, provider-sync failures and audit events. Filed payloads and gateway receipts are immutable at the database layer. Generated gap endpoints are no longer mounted.

ERP/logistics, tariff, sanctions, broker and government gateway adapters remain disabled until credentials, authoritative snapshots, replay fixtures, signature verification, retry behavior and failure contracts exist. HS classification, fuzzy-match thresholds, licenses, jurisdiction rules and filings require qualified customs/trade-compliance review. No application output is a government filing or legal determination without that review and a real gateway receipt.
